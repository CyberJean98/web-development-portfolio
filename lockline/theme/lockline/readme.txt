Block theme for Lockline Security, a small-business cybersecurity firm. Portfolio concept by Jean Berrios-Marquez.

== Description ==

Built from the Lockline design system (../../design-system/) and brand book (../../brand-book.md),
using the HTML example (../../index.html) as the reference.

Templates: front page, blog index, page, single post, 404.
Patterns (Lockline Security category): Hero with sample report, What we check, Plans table,
Who we help, Contact row.

The sample report is a Custom HTML block so its severity tags and score ring stay exact.
Edit the findings text directly in that block.
