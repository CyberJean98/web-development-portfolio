Block theme for Northbound Roofing, a Central MA roofing contractor. Portfolio concept by Jean Berrios-Marquez.

== Description ==

Built from the Northbound design system (../../design-system/) and brand book (../../brand-book.md),
using the HTML example (../../index.html) as the reference.

Templates: front page, blog index, page, single post, 404.
Patterns (Northbound Roofing category): Hero with quote form, Services with prices, How a job goes,
Towns we cover, Recent jobs, Emergency call band.

The quote form in the hero is a static demo. On a real site, replace it with a form plugin
block (for example WPForms or Contact Form 7) so requests are emailed to the owner.
