Block theme for Brasa, a wood-fired kitchen. Portfolio concept by Jean Berrios-Marquez.

== Description ==

Built from the Brasa design system (../../design-system/) and brand book (../../brand-book.md),
using the HTML example (../../index.html) as the reference.

Templates: front page, blog index, page, single post, 404.
Patterns (Brasa category): Hero with oven menu, Our story with facts, Two-column menu,
Hours and location, Private events band.

Every homepage section is a pattern, so the owner can edit dishes, prices and hours
in the Site Editor without touching code.

== Installation ==

1. Appearance > Themes > Add New > Upload Theme, choose brasa.zip.
2. Activate. The front page uses the front-page template automatically.
